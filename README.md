# Арт текстиль Ирины Уткиной

Шаблон интернет-магазина: шёлковые платки, шарфы и палантины в технике экопринт + мастер-классы.

## Структура
- `index.html` — единственная HTML-страница; разделы переключаются по адресу `#catalog`, `#item-1`, `#masterclasses`, `#portfolio`, `#contacts`.
- `assets/js/data.js` — **весь контент**: товары, разделы каталога, мастер-классы, соцсети. Чтобы добавить товар — скопируйте объект в `products`.
- `assets/js/i18n.js` — английская версия: подписи интерфейса и переводы товаров, разделов, мастер-классов.
- `assets/js/legal.js` — юридические документы (шаблоны). Реквизиты продавца задаются в `SELLER` в начале файла.
- `assets/js/app.js` — отрисовка страниц, корзина, заявка, переключение языка, cookie-уведомление.
- `assets/css/style.css` — стили (цвета и шрифты — в начале файла).
- `assets/img/products/pN-M.jpg` — фото товара N; `assets/img/craft/` — фото тканей и мастер-класса.
- `assets/img/logo.svg`, `favicon.svg` — тестовый логотип (монограмма IU).
- `assets/video/process.mp4` — вертикальное видео процесса (сжато до 540×960).

## Публикация
GitHub → Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
Сайт будет доступен по адресу `https://depresar.github.io/art-textile-irina-utkina/`.

## Что пока демо
- Форма заказа в корзине никуда не отправляет заявки (нужно подключить Telegram-бота, почту или оплату).
- Запись на мастер-класс: даты и время демонстрационные, заявки никуда не отправляются.

## Перед запуском продаж
- Заполнить реквизиты в `assets/js/legal.js` (всё в [квадратных скобках]) и согласовать документы с юристом.
- Подать уведомление об обработке персональных данных в Роскомнадзор.
- Заявки из форм хранить на сервисах с серверами в России (152-ФЗ, локализация данных).
- Настройка галочки согласия: `settings.consentPrechecked` в `assets/js/data.js`.
